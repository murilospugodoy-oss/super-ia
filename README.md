# ZEUS AI LITE — PLATAFORMA DE DESENVOLVIMENTO COM INTELIGÊNCIA ARTIFICIAL LOCAL

## Visão Geral

ZEUS AI LITE é uma plataforma de desenvolvimento com inteligência artificial local, projetada para Windows 10 e Windows 11. Oferece uma alternativa local ao Lovable, permitindo a criação de sites, aplicativos, programas, sistemas completos e projetos de programação usando modelos de IA locais GGUF e provedores online opcionais.

## Hardware de Referência

- Processador Intel Core i7.
- 16 GB RAM.
- NVIDIA GeForce GT 640.
- Windows 10 64 bits.
- Prioridade: baixo consumo de memória.
- Processamento principal pela CPU.
- GPU opcional, somente se compatível.

## Tecnologias

### Frontend

- React.
- TypeScript.
- Vite.
- Tailwind CSS.
- Interface responsiva.

### Aplicativo Windows

- Tauri ou Electron.
